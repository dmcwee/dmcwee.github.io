My-Azure is a Powershell Module to streamline some common tasks for deploying Azure Resources using Bicep or JSON ARM templates.
<!--more-->

> **Change Log**
> As of July 2025 My-Azure has been tested and works with PowerShell 7 and Bicep modules as well as the original Azure JSON modules.
> As of 11/1/2019 My-Azure has been updated to to use the Azure Az Module.  If you cannot upgrade to the Az Module you can get the latest version of My-Azure for the RM Modules by checking out the Release-AzureRm tag.

The documentation for My-Azure PowerShell module is maintained at the [MyAzure Github Repository](https://github.com/dmcwee/my-azure/).
